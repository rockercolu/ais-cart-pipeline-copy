    How AI's Cart checks a purchase

    1. ReadMuse Spark 1.3 reads every price and term off the screenshot, marking each as observed, inferred or unknown.
    2. CheckPlain code checks the math and looks for missing renewal prices.
    3. Re-readMuse Wonder 1.0 takes a second look at only the fields the checks flagged.
    4. DecideMuse Spark gives the answer from the checked facts. Code holds back any approval that fails a check.
